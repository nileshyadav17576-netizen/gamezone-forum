# 🎮 GameZone: Gaming Community Forum

An interactive community forum for gamers, built with HTML, CSS and JavaScript.

**Live demo:** [Open GameZone](https://nileshyadav17576-netizen.github.io/gamezone-forum/)

## Features
- Create and delete your own posts, with a game category
- Like, comment on, bookmark and share posts
- Search posts by text, game or user
- Filter by game; Home, Trending and Bookmarks views
- Join game communities and see notifications
- Profile popup with post and like stats
- Posts and settings saved in the browser (localStorage)
- Responsive layout for mobile and desktop

## Technologies Used
HTML5, CSS3, JavaScript, localStorage, GitHub Pages

## Project Structure
| File | Purpose |
|---|---|
| index.html | Page structure |
| style.css | Styling and responsive layout |
| posts.js | Post data, saving and rendering |
| features.js | Likes, comments, search, filters, navigation, notifications |
